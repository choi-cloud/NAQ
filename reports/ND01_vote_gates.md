## ④ 실패·경고·이상·지시서에 없어 정한 것

- 실패한 arm·정지 사유 없음. push 실패 없음. `a2`는 2GB 한도 안이라 빼지 않았다.
- 시작 시 작업 트리: `CLAUDE.md` 수정과 지시서 외에 `results/Amazon_clothing/`, `results/hl/hl02/`, `results/hl/p0/Amazon_clothing/`가 미추적으로 있었다. 커밋하지 않았다.
- GPU 최대 할당: selfcheck 9.94 GB, 관문 A 7.37 GB, 관문 B 7.37 GB. CLAUDE.md §2의 "6GB 안" 메모보다 크다. 시작 시 사용량은 2 MiB / 16376 MiB였다.
- 지시서 머리말의 "§4(평가)와 §5(AUROC 채점)"는 본문의 §2-2·§3-3에 해당한다고 보고 그렇게 적용했다.
- `vote_rows`: `W.index_select` 대신 CSR 배열(`crow_indices`·`col_indices`·`values`)로 행을 골랐다. selfcheck에서 `torch.sparse.mm` 전체 계산과의 최대 차이 3.28e-06(`nd_vote.py`의 값, `selfcheck.json`).
- `a2`: `torch.sparse.mm` 결과를 float64 scipy 행렬로 옮겨 행 정규화한 뒤 float32로 되돌렸다.
- 에피소드별 정확도 파일 이름: `results/nd/nd01/gateA/<shot>shot/<arm>_<pool>.npy`(지시서의 `<arm>.npy`에 pool을 붙였다).
- 선택의 동률 규칙: 격자 순서(f → tau 0.05, 0.1, 0.2, hard → nbr 1hop, self, a2), λ 0.25, 0.5, 0.75 순으로 처음 나온 최댓값. 이번 run에서 동률은 없었다(TA3의 tied 열).
- CI: `1.96 × std(ddof=0) / √n`(exp027과 같은 식). paired 열·TB2도 같은 식. `paired_win_frac`·`positive_frac`은 차이 > 0인 비율이고 동률은 분모에 포함한다.
- TA1에 `feat_*` 행과 `vote_*`·`comb_*` 행 모두 같은 f의 `feat_<f>` 대비 paired 열을 채웠다. `comb_<f>_sel` 행은 별칭 행으로 추가했다.
- 지시서에 없는 기록: 상위 두 logit이 정확히 같은 query 비율(test, `selection.json`의 `test_tie_frac`). argmax는 앞 슬롯을 택한다(exp027과 같음). 0 초과인 base arm — 1shot: `feat_x` 0.0157, `vote_x_hard_1hop` 0.0616, `vote_x_hard_self` 0.0562, `vote_x_hard_a2` 0.0003, `vote_a2x_hard_1hop` 0.0142, `vote_a2x_hard_self` 0.0125; 5shot: `vote_x_hard_1hop` 0.0045, `vote_x_hard_self` 0.0061, `vote_x_hard_a2` 0.0000, `vote_a2x_hard_1hop` 0.0050, `vote_a2x_hard_self` 0.0044. z0·z2에 영벡터 행은 없다. `feat_x` 동률의 원인은 확인하지 않았다.
- 표 생성 뒤 `nd_nd01_tables.py`의 NDP 값 표시 자릿수를 소수 2자리에서 4자리로 바꿨다(반올림으로 NDP001·NDP006의 Δ 표시가 달라져서). 수치 자체는 바뀌지 않았다. 이 변경은 report 커밋에 들어 있다.
- 관문 A를 `test_tie_frac` 추가 후 한 번 더 실행했고, `TA1_gateA.csv`는 첫 실행과 바이트 단위로 같았다.
- 관문 B: `hl008.b4_scores`를 복사 없이 import했다(batch 256, ppr_alpha 0.15, ppr_iters 30, tau 0.3; `ax`·`a2x`·`enc_n`과 후보만 사용). `enc_n` 자리에 enc_b 임베딩을 넣고 열 이름을 `enc_b`로 썼다.
- 관문 B anchor: 2,000개 중 고유 1922개, 중복 anchor는 별개 행으로 센다. 양·음이 다 있지 않아 AUROC에서 빠진 행: all 8개, far50 325개. 후보 same-class 비율 0.1790. `auroc_pooled`는 2,000행 전체로 계산했다.
- `auroc_far50`: a2x 점수 내림차순(stable) 뒤쪽 400열. 행 필터는 `hl010_diag_pdd`의 P2와 같다.
- NDP010의 기준값은 지시서의 0.7564를 썼다.
