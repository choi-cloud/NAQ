## ④ 실패 · 경고 · 이상
- 40 run 모두 완료, 실패 없음. push 실패 없음. deprecation 경고 외 경고 없음.
- §0 `git status`: 추적 파일 변경은 없었고, 비추적은 `out/`, `results/hl/hl02/`, `results/hl/hl03/`(HL03 실행 산출물)뿐이었다. 진행.
- `hl007`은 hl005의 점수 함수(`pair_scores`, `ppr_columns`, `encoder_embeddings`, `sym_adjacency`)를 **복사하지 않고 import**했다(정의 동일성 보장 목적). anchor는 `results/hl/hl03/g0/anchors.npy`를 읽고, 같은 seed로 다시 뽑은 것과 같은지 확인했다(일치).
- **`comb` 정의 차이**: G0b의 `comb`는 HL03 hl005와 같은 `mv + enc_b`(지시서 "점수 정의 완전히 같게")이고, G2의 `comb_top10`은 지시서 표대로 `mv + enc_n`(NaQ seed 1212 teacher)이다. G0b에 `mv + enc_n` 행은 추가하지 않았다. G2 `comb_top10`의 실제 순도는 T7(0.5297).
- G0b 선택 규칙 구현: 동률은 X 순위 순(hl005와 같음). `mid:m`은 점수 상위 m개를 X 순위로 다시 정렬한 뒤 인덱스 (m−10)//2부터 10개. `rand`는 `np.random.default_rng(1212)`. B3·B5에도 `choi`·`rand` 행을 함께 계산해 csv에 있다.
- G2 구현:
  - `rand10`·`shuf_comb`의 난수는 run seed로 만든 별도 numpy Generator(학습 RNG와 분리). `shuf_comb`는 anchor별 B4 후보의 `comb` 점수를 무작위 치환한 뒤 상위 10.
  - `mv_mid30` = `mv` 상위 30을 X 순위로 정렬한 뒤 중앙 10(인덱스 10–19).
  - `p04_choidiff`의 "필터 통과 GT-diff"는 **B4 안**(X 순위 201–1000)으로 한정했다(G1과 거리 조건을 맞추기 위함; 지시서에 범위 명시 없음). 부족분은 B4 비통과 GT-diff의 X 중앙에서 채웠고 그 비율을 기록했다. same 4개는 G1 p=0.4와 같은 규칙.
  - anchor는 hl003 `uniform`과 같은 코드 경로(seed 1212 `original_gt_match` 0.59771, HL03과 같음).
- HLP047의 G1 곡선 값은 선형 보간(위 ② 설명). `rand10`·`shuf_comb`는 순도 0.179로 G1 범위 밖이라 계산하지 않았다.
- G2 시작 전 `hl008`을 `--epoch 20`으로 두 arm(comb_top10, p04_choidiff)만 scratchpad에서 돌려 동작을 확인했다(결과 디렉터리 밖, 표에 미포함).
